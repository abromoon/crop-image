# SNIP

**S**imple **N**o-upload **I**mage **P**rocessing.

Инструменты для обрезки изображения с выбором якоря (сверху / по центру /
снизу / слева / справа). В веб-версии — по любым пропорциям (квадрат, форматы обоев
рабочего стола 16:9, 16:10, 21:9, 32:9 и др. или свои), CLI режет в квадрат — без сохранения истории и без загрузки изображений куда-либо.

## Веб-версия (GitHub Pages)

Статическая страница в папке `src/` (`index.html` + `style.css` + `app.js`). Никакого бэкенда и
сборки — вся обработка происходит в браузере через Canvas API.

- Перетащите изображение в область (или выберите файл кнопкой).
- Выберите пропорции: 1:1, форматы обоев рабочего стола (16:9, 16:10, 21:9, 32:9, 3:2, 4:3, 5:4)
  или свои. Рамка берёт максимально возможный размер, картинка не масштабируется.
- Выберите якорь обрезки кнопками на схеме 3×3 (включая диагонали) или передвиньте рамку на превью.
- Нажмите «Скачать» под изображением — файл сразу сохранится в папку загрузок браузера.

Изображение никогда не покидает браузер: ни загрузки на сервер, ни сохранения
между сеансами. В `localStorage` запоминается только выбранная тема оформления.

Шрифты [Roboto Flex](https://fonts.google.com/specimen/Roboto+Flex) и
[Google Sans](https://fonts.google.com/specimen/Google+Sans) (SIL Open Font
License 1.1, лицензии — в `src/fonts/`) лежат вместе с приложением, так что
страница не обращается к сторонним серверам. Иконки —
[Material Symbols](https://fonts.google.com/icons) (Apache License 2.0).

### Установка как приложение (PWA)

Страницу можно установить как приложение, после этого она работает и без
интернета.

- **Chrome / Edge на компьютере** — значок установки в адресной строке.
  Установленное приложение появляется в «Открыть с помощью» для PNG, JPEG,
  WebP, GIF, AVIF и BMP.
- **Android (Chrome)** — меню → «Установить приложение». После установки
  фото можно отправить в приложение через «Поделиться» из галереи.
- **iPhone / iPad (Safari)** — «Поделиться» → «На экран „Домой“». Открытие из
  файлов и «Поделиться» в приложение Safari не поддерживает.

### Про качество

- **PNG** — обрезается по-настоящему без потерь (Canvas работает на уровне пикселей).
- **JPEG/WebP** — при сохранении браузер неизбежно перекодирует файл заново
  (Canvas API не умеет резать JPEG на уровне DCT-блоков, как `jpegtran`). Экспорт
  идёт с максимальным качеством, потери минимальны, но не гарантированно нулевые.
  Интерфейс явно предупреждает об этом для таких файлов.
- Прочие форматы, которые браузер не умеет сохранять напрямую (например, BMP),
  экспортируются как PNG.

### Деплой на GitHub Pages

Деплой автоматический, через `.github/workflows/deploy.yml` (GitHub Actions):
каждый push в `main` собирает и публикует сайт заново.

1. Запушить этот репозиторий на GitHub.
2. Один раз в настройках репозитория: **Settings → Pages → Build and
   deployment → Source: GitHub Actions**.
3. После первого прогона workflow (вкладка **Actions**) страница появится на
   `https://<username>.github.io/<repo>/`.

Сборка не требуется — workflow просто публикует содержимое папки `src/` как есть
(`src/index.html` становится корнем сайта).

## CLI-версия (Python)

`crop_image.py` — локальный скрипт на Pillow, делает то же самое из терминала и
сразу сохраняет **две** копии (якорь сверху и снизу):

```bash
python3 crop_image.py путь/к/image.png [output_dir_or_prefix]
```

Подробности — в докстринге самого скрипта.
